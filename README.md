# Hey, I'm Yotam 👋

I'm a full-stack developer based in Berlin. I like building products end to end, from defining the experience and architecture to making them reliable and enjoyable to use.

### Featured projects

- **[STACK](stories/stack.md)** — a physical-first card game evolved into a real-time multiplayer product. I built a deterministic rules engine, bots, a server-authoritative room system, WebSocket updates, and both Classic and Next.js/React tabletops. [Read the case study](stories/stack.md).
- **[CartShift Studio](https://github.com/CartShift/CartShift-Studio)** — my e-commerce development studio, and the tools I build to run it.
- **[Wake My Way](https://github.com/yotamon/WakeMyWay)** — an Android alarm app exploring a more personal, conversational way to wake up.
- **[Liquid Loom](https://github.com/yotamon/Liquid-Loom)** — tooling for developing Shopify themes.
- **[Ensemblis](https://github.com/yotamon/Atlas-Irwin)** — a platform for artists, growing out of my own music project, [Atlas Irwin](https://atlasirwin.com).

I mostly work with TypeScript, React, Next.js, Node.js and the backend technologies a product calls for. I've also been working with Kotlin and AI integrations.

Outside of code, I make electronic music and DJ. I'm drawn to the intersection of technology, design and creativity.
