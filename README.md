# Hey, I'm Yotam 👋

I'm a full-stack developer based in Berlin. I like building things end to end — from figuring out what a product should do to making it work well and feel good to use.

A few things I've been working on:

- **[CartShift Studio](https://github.com/CartShift/CartShift-Studio)** — my e-commerce development studio, and the tools I build to run it.
- **[Wake My Way](https://github.com/yotamon/WakeMyWay)** — an Android alarm app exploring a more personal, conversational way to wake up.
- **[Liquid Loom](https://github.com/yotamon/Liquid-Loom)** — open-source tooling for developing Shopify themes.
- **[Ensemblis](https://github.com/yotamon/Atlas-Irwin)** — a platform for artists, growing out of my own music project, [Atlas Irwin](https://atlasirwin.com).

I mostly work with TypeScript, React, Next.js and the backend technologies a project calls for. I've also been spending a lot of time with Kotlin and AI integrations.

Outside of code, I make electronic music and DJ. I'm drawn to the intersection of technology, design and creativity.
